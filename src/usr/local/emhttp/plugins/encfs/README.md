**EncFS**

Mount EncFS-encrypted directories on Unraid from the webGUI or the command line. Supports multiple volumes, password prompts that never touch disk or the process list, optional auto-mount from a password file, automatic unmount when the array stops, and backups of each volume's `.encfs6.xml` to the flash drive. Ships a statically linked encfs 1.9.5, so no extra libraries are needed.
